# Наша форма

Семейный трекер ежедневных взвешиваний Руслана и Насти на 12 недель. Предварительный приз каждый день, фиксированный приз по завершении каждой семидневной недели. Награды выплачиваются только за новые минимумы относительно предыдущего оплаченного рекорда.

## Публикация
GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Облачная синхронизация
1. Создайте проект Supabase.
2. Выполните SQL из setup.sql через SQL Editor. Таблицы защищены RLS, записи видит только соответствующий авторизованный аккаунт.
3. Укажите только Project URL и publishable key в config.js — не добавляйте service_role или секретный ключ.
4. Создайте семейный аккаунт на сайте, войдите с одними и теми же данными на обоих телефонах.
5. Для корректного подтверждения email укажите адрес GitHub Pages в Authentication → URL Configuration.

Пока Supabase не подключён, данные хранятся только локально на текущем устройстве.
